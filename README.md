## Purpose

The MVP demonstrates the end-to-end work order lifecycle, including:

- Role-based login
- Work order creation and tracking
- PM review and SOW upload
- Contractor quote submission
- Proof and invoice upload
- Admin master quote upload
- Client approval
- Payment status tracking
- Audit log visibility

## Status

MVP demonstration version.  
Not intended as the final production SaaS build.
